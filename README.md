# Seedance Studio · 界面试用版

独立运行的 Windows 桌面试用版，重新整理素材、提示词、生成和作品历史的界面。默认居中打开，窗口宽高约占当前屏幕可用区域的 80%，适配 Windows 显示缩放，保留手动最大化与缩放。主要操作也经过 1280 × 800 排版检查。

## 启动

本机可双击已有的 **Seedance Studio 试用版.lnk**。快捷方式包含本机路径，只在本地保留。克隆仓库后，先安装下文的依赖，再用 Python 运行 `start.pyw`：

```powershell
python -m pip install -r requirements.txt
pythonw start.pyw
```

提供 Windows 64 位免安装便携版：解压 `Seedance-Studio-Preview-Windows-x64.zip`，双击文件夹中的 `Seedance Studio.exe`。需保留整个文件夹及 `_internal` 目录；使用者无需安装 Python、Qt 或 FFmpeg。

便携版首次启动自动创建 EXE 旁的 `data/`：配置、加密密钥、历史、队列和素材库保存在其中，日志位于 `data/logs/`；成片默认保存到 EXE 旁的 `成片/`。分发包是空白配置，不读取制作人的旧资料目录。请解压到可写入的目录，例如桌面；更新时保留自己的 `data/` 和 `成片/`。已配置的密钥由当前 Windows 账号加密，更换电脑或账号时需重新配置。

**技术联系人：吴仕敏。** 不知道即梦 API Token 或中转站登录账号时，请联系吴仕敏索取文档和密钥。

以上 Python 启动步骤仅用于源码开发。源码运行需 Python、本项目依赖及 PATH 中的 FFmpeg/FFprobe。

首次迁移已复制原工具的设置、加密密钥、ChatGPT 登录、素材清单、提示词和历史。右上角可选择 ChatGPT 账号登录或 DeepSeek API Key 接入；启动时刷新上次选择的平台。DeepSeek 通过 API 分析文本和图片，校验密钥只读取模型列表，推理按接口用量单独计费。连接方式与额度来源见 [PLATFORM_LOGIN.md](PLATFORM_LOGIN.md)。

## 界面

- **创作**：左侧导入本地素材，中间统一编写创作提示词，右侧设定并提交生成。输入框中的全文就是提交给 Seedance 的文本；可直接提交，也可按需点击“抽帧并优化”后再生成。
- **素材**：按视频、图片、音频分组显示，只显示有素材的分类，保留文件名、用途、勾选与引用关系；支持本地文件选择和拖入；文件夹、用途、网址收进“导入素材”旁边的菜单。本地视频默认勾选用于生成，仍可逐秒抽帧；“上传视频”或素材菜单中的“上传并用于生成”自动获取参考地址。已有公开网址可继续使用。长文件名悬停显示完整名称。图片缩略图可点击预览；素材卡片右侧菜单可更改用途、插入 `@` 或移除。
- **视频上传**：“设置 → 视频上传账号”登录中转，密码仅通过 HTTPS 发送，登录凭据由 Windows 系统加密保存，密码不写入配置或日志。上传前校验真实容器、编码、大小、时长、尺寸、像素和帧率；显示发送百分比、等待中转返回地址的动画与计时。上传期间仍可滚动查看素材，导入及修改操作暂时禁用。调用记录保存连接与发送、等待响应的分阶段耗时。地址及有效期随素材和历史模板保存，保留完整签名。登录令牌自动续期；地址过期或本地视频变化后重新上传；旧分析记录不会因地址续期而失效。失败时显示中转返回的原因，保留本地文件与已成功上传的其他视频。
- **素材库 · 本地图片**：累计保留导入过的图片、角色图、场景图、首尾帧和选中的关键帧，包含缩略图、文件名、用途、保存时间、状态、搜索和预览。支持多选“添加所选”或“全部添加”（有搜索或筛选时仅添加当前显示的可用图片）。每张本地图片在工作室数据目录的 `image_library_files/` 中保存内容副本，相同内容与文件名不重复存储，不同内容的同名图片分别保存。图片无需上传云端，也没有 7 天期限。原文件移动或删除后仍可使用本地副本；原文件与副本均缺失时置灰并提示重新导入。首次启用会从全部调用/生成历史及移除记录补查旧图片，不受最近 20 条撤销记录限制。旧记录只包含路径时，已找不到的原文件无法凭记录重建图像。
- **素材库 · 已上传视频**：累计保存上传成功的视频，按文件名搜索并筛选可使用或已失效记录，显示文件名、时长、大小、上传及到期时间。有效期使用中转返回的 `expires_at`（通常为 7 天），不从重新打开工具或添加附件时重新计时。到期状态每秒检查；过期、有效期未知或剩余不足一分钟的地址置灰并禁止添加与新插入引用，旧地址也不能提交。失效记录保留，可手动重新上传本地文件获取新记录。文档没有云端列表/状态查询接口，目前依据上传回执管理生命周期，无法同步云端提前删除或其他设备上传的文件。
- **移除与恢复**：从附件移除不会删除本地文件或素材库记录；在“素材库 → 本地图片”可任意恢复所有保留的图片，在“已上传视频”选中有效视频，点击“添加到当前创作”即可恢复，不重复上传。“导入素材”旁的下拉菜单也提供素材库入口和“恢复上次移除的素材”。恢复不会重复添加同一图片，不改写现有提示词和生成方式；超出当前方式可选数量的图片仍加入附件但不勾选。恢复上次移除的图片也可使用本地副本。重新导入同一本地视频时，如果文件大小、修改时间未变且地址仍有效，会复用已上传地址。素材库的元数据和完整签名地址由 Windows 系统加密保存。
- **提示词**：输入 `@` 自动弹出素材列表，可继续输入文件名搜索，用方向键和回车或点击选择；选中后插入文件名引用并自动勾选。未勾选素材也可选择，重复文件名会区分。仅用于本地分析的视频不能直接引用。结构模板、恢复优化前原文、“查看创作方案参数”在编辑区右上角的菜单中。
- **生成**：只用 Seedance 2.5。全模态任务固定为“参考生视频”，编辑与延长选项隐藏，复用历史时也使用参考模式。分辨率、时长、比例、生成方式直接展示；时长只提供 4–30 秒和“自适应”（传入 `-1`）。格式、水印、尾帧等在“更多参数”中。设置与草稿自动保存，“预览请求”可核对实际参数并导出完整 JSON。
- **智能优化**：保留输入中的具体要求与结构，默认整理为 150–300 字，复杂分镜尽量不超过 500 字。优化前原文可恢复。“核对”只显示保留内容、角色对应和需要确认的问题，不提交给 Seedance。使用 ChatGPT 登录授权的会员共享额度。语音转写默认关闭，单独开启时需要 OpenAI 接口密钥并按接口用量计费。
- **优化按钮与任务提交**：抽帧/智能优化、素材引用、关键帧和字数只在“创作”页显示。后台查询生成状态不会禁用提示词和素材控件；分析、上传、提交或保存操作进行时暂时锁定相关输入。一次生成一个视频；生成期间可准备和优化下一条，点击“加入队列 · 付费”保存为独立待提交任务。
- **本地生成队列**：“待提交”页签显示待提交、提交中、服务端排队、生成中、保存中、已保存及异常记录。每条锁定加入时的提示词、参数、完整图片编码、参考地址、素材和保存目录；不会被后续编辑覆盖。按加入顺序逐条生成，当前成片保存后自动提交下一条。可暂停后续提交、继续队列、调整待提交项顺序、移出，或“移出并编辑”后重新加入；正在提交/生成的任务不能移除。队列与完整媒体快照以当前 Windows 账号加密保存，关闭后保留，重新打开先暂停待提交项，当前已接单任务可继续查询和自动保存。失败、地址过期、保存失败或提交未确认均暂停后续提交。提交未确认禁止自动重发，可核对后关联已接单任务编号，或确认服务器未接单后移出。队列只在程序运行时工作；付费请求在轮到本条时发送，移出未提交项不会调用生成接口。
- **视频分析流程**：点击“抽帧并优化”时，每秒抽一帧并补上结尾画面；ChatGPT 查看这些图片和角色图，识别情节、动作与镜头顺序后优化提示词、推荐 2–4 张关键帧。修改提示词、替换图片或参考视频后，默认保留当前提示词，按需主动重新分析。只填网址时尝试读取远程视频，推荐在素材菜单关联本地文件以稳定抽帧。
- **关键帧**：点击编辑区底部“关键帧”查看全部抽帧，预览和调整勾选。选中的关键帧会作为参考图片随角色图、原视频网址和提示词提交；提示词明确区分原片构图/动作参考与替换角色外观，避免把原片角色当成新的角色图。
- **提交步骤**：默认使用当前提示词直接生成或加入队列，无需先分析；素材变化和手动修改提示词不会强制调用 ChatGPT。未上传或地址到期时仍先上传，再继续本次已点击的生成。素材类型、数量、引用、有效期及生成参数始终校验。在“更多参数”中可主动开启“生成前自动分析”，此时参考素材未分析或发生变化才显示“先分析视频”。抽帧分析、单独上传和载入历史均不会自行提交收费任务。
- **成片**：成功后自动保存到设置中的目录；便携版默认使用 EXE 旁的 `成片/`，源码版默认使用“下载”下的 `Seedance Studio` 子目录，可播放、打开文件夹和对比优化提示词。在“设置 → 自动保存到”可选择其他目录；目录设置会保留。
- **生成进度**：收费生成请求开始后自动切换到“成片”，显示动画、提交→排队→生成→保存四个阶段、已等待时间。成片页只保留一条任务进度条；视频上传使用素材区进度，创作区的通用处理提示自动避让。已用时间显示在标题旁，等待预估独占整行，换行后完整显示。等待预估基于本机同类任务的实际耗时，样本不足时显示暂无样本；超过估算区间后明确显示仍在等待。提交未确认、查询暂停和保存失败不会显示为完成，也不会自动重发创建请求。
- **接口错误详情**：成片页和历史详情提供“错误详情”，右上菜单“调用记录”可查看所有异常清单。按环节显示 HTTP 状态码、业务错误码、请求/任务编号、耗时、接口地址、完整响应、参数和可能原因；查询 HTTP 成功但云端任务失败会明确区分。支持复制本条报告、导出筛选后的完整清单。新错误响应最多保留 2 MB，超过或读取中断会明确标注，密钥、登录凭据和素材签名始终隐藏。旧版本未保存的原文或错误码不能补回，显示“未收到 / 未记录”。常见原因属于排查建议，服务端根因仍需后台日志确认；参考 [火山引擎错误码](https://docs.volcengine.com/docs/ark/error-codes?lang=zh&redirect=1)。
- **提交等待时间**：创建视频任务的本地网络等待从 120 秒延长至 300 秒，界面统一显示约 5 分钟；查询单次响应仍为 30 秒，生成任务排队、运行期间继续自动查询。此值不会修改中转站或上游的超时设置；HTTP 408/504、连接超时或缺少创建任务编号会标为提交未确认，保存已有证据并避免自动重发创建请求。
- **历史记录**：编辑区新增“历史记录”页签，左侧“历史”可打开宽版列表。累计保存视频生成、提交未确认/失败和 AI 提示词版本；可筛选、搜索、播放、查看完整提示词和优化前原文。点击“载入再编辑”恢复素材、提示词和参数，修改后再点击生成。载入动作不会提交付费请求。
- **历史状态**：绿色标记“有成片 · 已保存”，红色标记提交/生成失败，黄色标记提交未确认或生成成功但保存失败/本地缺失，紫色标记进行中，灰色标记仅提示词版本。异常记录直接展示原因，完整记录保留全部错误信息与任务/提交编号；可按状态筛选，搜索也包含错误原因。提交未确认保留待核对状态，不视为已失败；查询异常显示最后确认的生成状态。
- **模板复用**：新生成记录同时保存分析结果、关键帧选择和抽帧目录，复用时保留。旧记录没有完整分析快照时沿用其已保存提示词与素材，仍可主动抽帧优化；后续生成保留来源任务关系。源素材文件需仍在本机，原视频网址需仍可访问。
- **用量**：展示视频条数、产出秒数、生成与总计费单位；支持导出中文用量表格，人民币金额在界面、历史详情和表格中统一保留两位小数。按用户提供的单价，无视频输入 70 元、有视频输入 42 元，每百万生成计费单位；“设置”可修改或清空单价。参考费用按当前单价和接口实际返回的生成用量估算，不使用旧版美元估算换算，也不计入结果未确认的提交；缺少单价或用量时显示未估算。实际费用以中转站账单为准。
- **中文界面**：比例“自适应”、智能优化、连接设置、状态提示、用量单位、标准弹窗和输入框右键菜单统一使用简体中文。参数预览和调用记录默认展示“中文说明”，另保留“原始参数”；复制及导出仍为真实接口参数。产品/模型名称、文件名、网址、任务编号和原始诊断保留原文。完整盘点见 [中文界面盘点.md](中文界面盘点.md)。

- **引用删除**：提示词中的 `@{文件名}` 作为一个整体删除；在引用末尾按退格、开头按 Delete，或只选中引用的一部分再删除/剪切，均移除完整引用。可一次撤销恢复，删除过程不唤醒素材选择框；输入新的 `@` 仍正常选择素材。
- **下拉列表**：生成设置、模型选择及各素材/历史筛选统一为白底列表，最多同时展示 8 项，超出部分滚动查看；系统深色外观不会在列表上下留下黑边。

## 开发与验证

运行环境：Python、`requirements.txt` 中的 Qt 组件，以及 PATH 中的 FFmpeg/FFprobe。视频抽帧进程不弹出终端窗口。

```powershell
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
```

回归检查覆盖客户端、登录、媒体及记录，以及新版创建→查询→自动保存、重启不重复提交、会员分析、统一输入提交、原文恢复、素材弹窗选择、素材变更校验、首尾帧顺序和按钮边界。测试使用模拟接口和临时数据，不产生收费视频。

本机界面渲染图位于 `previews/`，只在本地保留；设计说明见 `DESIGN.md`。

视频参考的官方规格表见 [参考视频要求.md](参考视频要求.md)。

## 构建 Windows 便携版

在 Windows 64 位环境中安装运行依赖与 `requirements-build.txt`。构建机需准备 FFmpeg、FFprobe 及其 DLL；可通过环境变量 `SEEDANCE_FFMPEG_DIR` 指定所在目录。

```powershell
python -m pip install -r requirements.txt -r requirements-build.txt
python -m PyInstaller --noconfirm --clean --distpath build/portable-output SeedanceStudio.spec
python package_portable.py
```

EXE 位于 `dist/Seedance Studio/Seedance Studio.exe`，可分发 ZIP 位于 `dist/Seedance-Studio-Preview-Windows-x64.zip`，另生成 SHA-256 校验文件。
打包过程只收集程序、界面资源和运行库，不复制个人设置、密钥、素材与历史。随包保留第三方许可与源码位置说明。
构建先输出到 `build/portable-output/`，打包完成后更新 `dist/` 的程序文件，保留已经运行后创建的用户数据。ZIP 只从空白构建目录生成。
打包校验在移除外部 Python/FFmpeg PATH 的子进程中运行，使用临时空白资料目录，验证 1280 × 800 窗口按钮边界、中文翻译、视频编码/抽帧/播放、Windows 加密和草稿保存；另在包含中文路径的独立便携目录中运行真实启动入口，验证自动创建数据与日志、各模块目录一致、旧资料目录不会干扰启动，不调用收费接口。校验失败不会生成分发 ZIP。
